# Credits

This project began as a PySide6 port of
[Minimalistic-Flat-Modern-GUI-Template](https://github.com/anjalp/Minimalistic-Flat-Modern-GUI-Template)
by [Anjal.P](https://github.com/anjalp), a frameless, dark design for PySide2.
It has since been rewritten as a plain Qt main window, and none of that design
remains, but the history of the repository starts there.

The current application, tests, documentation and tooling are by
[Cameron Brooks](https://github.com/CameronBrooks11).
